ハッキングが過去最多の今、Tangemという選択肢

PR2026年11月25日ぽんちゃい（PROP CHECK）

こんちゃ、ぽんちゃいです。

出金した利益、取引所や業者の口座に置きっぱなしにしていませんか。

2026年上半期、暗号資産のハッキングは212件でした。件数としては過去最多です（Blockaid調べ）。被害額は10億ドルを超えて、約11億ドル。ただしこれは件数の話であって、被害額が過去最多だったわけではありません。

狙われるのは、ネットにつながった場所に置かれた資産なんですよね。しかも預けている側は、起きてしまったら何もできない。プロップファームや海外FXで出した利益も同じです。業者の口座に溜めっぱなし、出金先の取引所に置きっぱなし。正直、これがいちばん怖い状態だと思っています。

そこで今回は、鍵を自分で持てるカード型のウォレット「Tangem（タンジェム）」を取り上げます。スマホにタッチするだけで使えて、電池も充電も要りません。

日本ではウォレットを触ったことがない人のほうが多いと思うので、「ウォレットとは何か」から書きました。出金を受け取って日本円にするまでの手順は、こちらの記事にまとめました。

そもそもウォレットとは

プロップの報酬をUSDTやUSDCで受け取ると、置き場所はだいたい2つです。取引所に置くか、自分のウォレットに置くか。

取引所の口座は、銀行にお金を預けているのに近い状態です。暗号資産を動かすための「鍵」は、取引所が持っています。取引所や業者が口座を止めると、自分では動かせません。

ウォレットは、その鍵を自分で持つための道具です。極端な話、業者がサービスを止めても、鍵が手元にあれば資産は動かせます。その代わり、鍵をなくしたら誰も助けてくれません。

この先に出てくる言葉を、先に4つだけ押さえておきます。

言葉意味身近なものにたとえると
鍵暗号資産を動かすための情報。これを持っている人が持ち主です金庫の鍵
アドレス送ってもらうときに相手へ伝える、英数字の長い文字列口座番号
ネットワーク暗号資産が通る道。同じUSDCでも、Ethereum、Arbitrum、Solanaなど何種類もあります鉄道の路線。路線が違うと届きません
ネットワーク手数料送るたびにかかる手数料。その道の通貨で払います（EthereumならETH）切符代

Tangemとは

見た目は、交通系ICカードそのままですね。スマホのアプリを開いて、カードを背面にタッチして使います。鍵はカードのチップの中で作られて、外に出ません。

指輪として持ち歩けるリング型も販売されています。

  • カードは2枚か3枚のセット。全部のカードに同じ鍵が入るので、1枚なくしても残りで使えます。
  • 標準では、12語のシードフレーズ（復元用の合言葉）を使いません。設定はできますが、作らない方がよい、とされています。紙に書いて保管しなくていい代わりに、カードを全部なくすと誰にも復旧できません。
  • 100以上のブロックチェーン、2万種類以上のトークンに対応しています（公式サイトの表記）。
  • チップはEAL6+認証、防水・防塵はIP69K、保証は25年です。

作っているのはスイスのTangem AGという会社です。2019年にSBIグループから1,500万ドルの出資を受けたと報じられています。

買うなら、公式サイトからをおすすめします。あとで書きますが、他社のウォレットでは、改造された端末が出回った事件がありました。私の場合、公式サイトで注文してから届くまで、1週間ほどでした。

届いてから使えるまで

  1. スマホにTangemアプリを入れる。iOS 15以上かAndroid 6.0以上で、NFCが使える機種が必要です。

  2. アプリで「スキャン」を押して、カードをスマホの背面に当てる。ケースは外したほうが読み取りやすいです。

  3. 「ウォレットの作成」を選ぶ。ここで鍵がカードの中に作られます。

  4. 残りのカードを、バックアップとして登録する。

  5. アクセスコード（暗証番号にあたるもの）を決める。

バックアップは最初に全部登録する。気をつけたいのは4番です。3枚セットなら、ここで残りの2枚とも登録してください。1枚だけ登録して終えると、あとから追加できません（公式ヘルプの記載）。

安全性：メリットとデメリット

先に言っておくと、ハードウェアウォレットに「絶対安全」はありません。ただその中で、個人が手軽に始められる対策のひとつとして、私は有力だと思っています。

メリット

外部の監査を受けている（Kudelski Security 2018年、Riscure 2023年）。アプリのコードは公開メーカーの自己申告だけに頼らなくていい
スマホには鍵が入っていないスマホをなくしても、新しいスマホにアプリを入れてカードを読めば元通り使える

内容使う側から見ると

どの1枚でも、単独で全額を動かせる1枚盗まれたときに守ってくれるのは、アクセスコードだけ

実際に気をつけるリスクは4つ

弱みを並べると多く見えますが、普通に使っていて資産を失う場面は、正直この4つくらいです。

リスクどういうときに起きるか防ぎ方
自分で承認してしまう偽サイトや偽のアドレスへの送金を、自分でカードを当てて承認する承認の前に、送金先とネットワークをスマホ画面で見比べる。初めての宛先は少額から
カードを1枚盗まれるアクセスコードを設定していない、または推測されやすい推測されにくいアクセスコードを必ず設定する
カードを全部なくす3枚を同じ場所に置いていて、火事や盗難にあう3枚を別々の場所に保管する
残り1枚でアクセスコードを忘れるコードのリセットにはカードが2枚要る1枚なくしたら、早めに新しいセットへ資金を移す

Tangemは「3枚のうち2枚そろえば動く」仕組みではありません。どの1枚でも、単独で全額を動かせます。カードを拾った人や盗んだ人がいても、アクセスコードが分からなければ資金を盗むことはできません。

アクセスコードを間違えると、6回目以降は1回ごとに待ち時間が1秒ずつ延びて、最大45秒になります。短い数字だけの、推測されやすいコードは避けましょう。

状況どうなるか
スマホをなくした影響なし。新しいスマホにアプリを入れて、カードを読み取る
カードを1枚なくした残りのカードで、そのまま使える
なくした分を補充したいできない。作成済みのウォレットに、あとからカードを足すことはできない
アクセスコードを忘れたカードが2枚あればリセットできる
カードを全部なくしたシードフレーズなしの設定だと、資金は戻らない

私なら、1枚なくした時点で新しいセットを買って、資金を移します。なくしたカードが誰かの手にあるかもしれないし、残りが減るほど上の4つのリスクが大きくなるからです。

Tangemで過去に起きたこと

都合の悪い話も書いておきます。確認できたのは2件です。

  • 2024年12月、Androidアプリの不具合。シードフレーズで作ったウォレットの秘密鍵がアプリのログに記録され、サポート担当が見られる状態になっていました。対象は、作成から7日以内にアプリ経由でサポートに連絡した人です。Tangemは「全体の0.1%未満で、資金の流出はない」と説明し、12月30日に修正しています。
  • 2026年7月、競合のLedgerの研究チームが攻撃手法を公表。レーザーでチップを誤動作させて、パスワードを再設定できるというものです。カードの現物と、約25万ドルの設備が要ります。修正はできません。Tangemは「一般の利用者へのリスクは事実上ない」と反論しています。

ほかのウォレットと比べると

メタマスクと比べると

ウォレットと聞いて最初に名前が挙がるのは、メタマスク（MetaMask）だと思います。スマホやPCに入れる無料のアプリです。私も以前のnoteでは、メタマスクからSBI VCトレードへ送って円転する手順を書きました。Tangemとのいちばんの違いは、鍵の置き場所です。

Tangemメタマスク
鍵の置き場所カードのチップの中スマホやPCの中
ネットとの距離鍵はネットにつながらない鍵が、ネットにつながる機器の中にある
復元の方法予備のカード12語のシードフレーズ
費用カード代がかかる無料
向いている使い方まとまった額を置いておく少額をすぐ動かす

メタマスクは無料ですぐ始められます。ただ、鍵がスマホやPCの中にあるので、その機器がウイルスに感染したり、偽サイトにシードフレーズを入力してしまったりすると、資産を抜かれます。極端な話、スマホ1台の安全性に全額を預けることになります。

個人的には、プロップの出金のようにまとまった額を置くなら、鍵をネットから切り離せるものが本命です。メタマスクは、少額を動かす用として分けて使えば十分だと思っています。

画面付きのウォレットと比べると

ハードウェアウォレットで有名なのは、LedgerやTrezorのような画面付きの端末です。Tangemとの違いを並べます。

Tangem画面付きの端末（Ledger、Trezorなど）
送金内容の確認スマホの画面で見る端末の画面で見る。スマホやPCが乗っ取られていても気づける
復元の方法予備のカード（シードフレーズなしが標準）12〜24語のシードフレーズ
中のプログラム書き換えできない更新できる。欠陥を直せる反面、偽の更新に注意が要る
電池と接続電池なし。スマホにタッチUSBやBluetooth。電池入りの機種もある
狙われやすいところカードの現物と、スマホ画面の表示シードフレーズ

送金内容を端末の画面で確かめられるのは、画面付きのはっきりした強みです。ただ、画面があれば安心、とは言い切れません。端末そのものを改造された事件が、実際に起きています。

  • 2023年、改造されたTrezor。セキュリティ会社のKasperskyが報告した事例です。個人売買サイトで買ったTrezor Model Tの中身が入れ替えられていて、シードフレーズが最初から犯人の知っているものになっていました。箱のホログラムシールは無傷で、画面も操作も本物と同じでした。入金から約1か月後に資金を抜かれています。
  • 2021年、改造されたLedgerが自宅に届く。Ledgerは2020年に顧客情報が流出していて、約27万人分の連絡先が公開されました。その住所あてに「交換用」と称する改造済みのLedger Nano Xが送られ、付属のアプリにシードフレーズを入力させる手口でした。

どちらも、シードフレーズを狙った事件なわけです。Tangemはシードフレーズなしが標準なので、同じ手口はそのままでは通りません。一方で、画面がない弱みはそのまま残ります。

どの端末でも共通して言えるのは、公式から買うことです。Tangemも例外ではありません。中古のカードは、売り手が同じ鍵の入った予備のカードを手元に残しているおそれがあります。

Tangem Pay：チャージ式のVisaカードも使える

Tangem Payは、USDCやUSDTをチャージして、Visaの加盟店で払えるバーチャルカードです。Apple PayとGoogle Payに登録できます。日本では2026年4月に提供が始まりました。

運営は米国のPaera LLCで、カードの発行はRainという会社です。Tangem AGは運営していないと、公式に明記されています。

私なら、Basicで十分です。Plusとの還元の差は1%なので、月額29.99ドルの元を取るには月に約3,000ドルの支払いが要ります。チャレンジ代とツール代だけでそこまで使う人は、多くないはずです。

申し込みから使えるまで

Tangemウォレットを持っていることが前提です。プランは、本人確認のあとにアプリの中で選びます。

  1. TangemアプリでTangem Payを開いて、バーチャルカードを作る。

  2. 本人確認をする。公的な身分証と、住所が必要です。

  3. USDCかUSDTをチャージする。

  4. カード情報をGoogle PayかApple Payに登録する。スマホに届く確認コードを入力すれば、店頭のタッチ決済で使えます。

承認されると、カードは通常5分以内に発行されます（まれに最大48時間）。

気をつけたいのは3番です。外から送ってチャージできるのは、Polygon、Base、BNBチェーン、ArbitrumのUSDCかUSDTです。出金を日本円にするときに使うEthereumは、この一覧に入っていません。

対応していないネットワークで送ると資金は戻らない、と公式ヘルプにあります。Tangemウォレットの中のステーブルコインは、アプリ内の交換を通してチャージできます。

セキュリティ：被害を小さく抑えやすい

クレジットカードの番号が流出すると、利用枠いっぱいまで使われるおそれがあります。Tangem Payは仕組みが違うので、被害の上限を自分で決められます。

仕組み使う側から見ると
チャージ式使えるのはチャージした残高まで。カード情報が流出しても、入れた額より多くは抜かれない。資産の本体はTangemウォレットに残る
1日の上限を自分で決められるアプリで金額を入れると、すぐ反映される。0ドルにすれば支払いを止められる
凍結アプリで押すだけで、新しい支払いを止められる。残高はそのままで、解除もすぐできる
すぐ再発行できるアプリで再発行を押すと、古いカード情報はその場で使えなくなる。新しいバーチャルカードは通常5分以内に届く
Google Pay・Apple Pay支払いのたびに指紋や顔での確認が要る。再発行したときは、新しいカードを登録し直すだけ
カードを分けられるBasicでも3枚まで持てる。毎月の利用料用と、その都度の支払い用を分けられる

バーチャルカードとGoogle Payの組み合わせなら、実物のカードが届くのを待つ必要がありません。番号が漏れたかもしれないと思ったら、その場で凍結して、数分で新しい番号に切り替えられます。

私なら、カードには次の支払いに使う分だけを入れておきます。使わない間は凍結するか、1日の上限を0ドルにします。極端な話、残高が100ドルなら、最悪でも失うのは100ドルです。

注意点もあります。

  • 支払いへの異議申し立てはVisaの手続きで進み、1件30ドルの手数料がかかります。返金は通常3〜14営業日です。
  • 実物のカードの再発行の手数料は、料金表では1ドル、ヘルプでは5ドルと、記載が分かれています。

私なら、経費の支払い専用にする

私なら、Tangem Payはトレードの経費を払う専用のカードにします。プロップのチャレンジ代や、TradingViewの利用料です。どちらもドル建ての請求なので為替手数料がかからず、回数も少ないので記録が追いつきます。税金の計算との関係は、こちらの記事で書いています。

私ならこう使う

私なら、Tangemは「出金した利益の置き場所」として使います。業者の口座には利益を溜めない、取引所にも置きっぱなしにしない、が基本です。

  • まとまった額は、Tangemに置く
  • すぐ動かす少額は、メタマスクなどに分ける
  • カードは3枚を別々の場所に保管する

私なら守ること5つ

ここまでの話をまとめると、守ることは5つです。

  • 公式サイトから買う。中古や転売品は使わない
  • シードフレーズなしの設定で使う（2024年の不具合は、シードフレーズで作ったウォレットで起きました）
  • 3枚セットを選んで、別々の場所に保管する
  • アクセスコードを必ず設定する（6文字以上。数字だけにしない）
  • 承認の前に、送金先とネットワークを必ず見比べる

極端な話、3枚とも自宅の同じ引き出しに入れていたら、火事や盗難で全部なくなります。2026年7月に公表されたレーザーの攻撃も、カードが相手の手に渡らなければ成り立ちません。守るべきものは、カードの現物です。

ここまでの話は、出金を受け取ったあとの置き場所の話です。とはいえ、ウォレットを用意しても、業者が払ってくれなければ意味がありません。出金できるかどうかは、ウォレットより先に業者選びで決まります。各社の出金報告と拒否・BANの記録はPROP CHECKに、ルールで気をつけたい点はプロップファームのルールで気をつけることにまとめています。

業者選びで出金の見込みを確かめて、受け取ったお金はTangemで自分で守る。私はこの順番がいちばん安心だと思っています。
