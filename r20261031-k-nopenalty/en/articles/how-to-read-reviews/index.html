How to read our review counts

Post counts are not the same as user counts

One account may post more than once, so the number of reports confirmed per firm is not the number of people harmed or of independent incidents. Some reports fall into more than one type.

The reference score is not a safety ranking

It is a reference value that summarizes the breakdown by how each post relates to the firm, calculated the same way for every firm. We show the number of accounts, small samples and the collection period alongside it, and do not translate it into safety, refusal rates or payout-success rates.
