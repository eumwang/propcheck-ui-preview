METHOD

評価方法

PROP CHECK の点数が、何をもとに、どう計算されているかを説明します。はじめての方は、上から順に読むと全体がつかめます。

このページで分かること

  • 総合参考点が、どの点数からできているか
  • 出金可否・本人口コミ・運営基盤を、それぞれ何を見て採点するか
  • すでに購入した人や既存の口座にさかのぼって不利な変更をした会社と、告知なしで重大な変更をした会社への減点
  • 点数を読むときの注意

目次

  1. 総合参考点
  2. 出金可否
  3. 本人口コミ
  4. 運営基盤
  5. 履歴変更の追加減点

点数ができるまで

  1. それぞれの点数を出す出金可否・本人口コミ・運営基盤を、それぞれ採点します。
  2. 重みをつけて合わせる下の割合で合わせ、「履歴減点前の参考点」にします。
  3. 必要なら減点するすでに購入した人や既存の口座にさかのぼって不利な変更をした会社と、告知なしで重大な変更をした会社は、追加で減点します。
  4. 総合参考点になるこうして出た点数が「総合参考点」です。

ことばの説明

総合参考点

本人報告

1. 総合参考点

出金可否・本人口コミ・運営基盤の点数を決まった割合で合わせ、必要に応じて履歴変更の追加減点を引いた点数です。

履歴減点前の参考点
=
出金可否50％
+
本人口コミ20％
+
運営基盤30％

注意実際の出金成功率や安全確率ではありません。

出金可否の点数、口コミ点、画面の表示で使う期間はそれぞれ異なります。

2. 出金可否

出金できたかどうかについての、本人報告をもとにした点数です。

注意報告が少ない会社の点数は、限られた情報に基づいています。点数の高さだけで安心とは判断しないでください。

集計期間全期間

本人報告は、古いものも含めてすべて集計します。

出金できたか、問題があったかを確認します。報告の時期で重みを変えず、古い報告も新しい報告も同じ扱いで評価に反映します。

対象と除外

投稿文の内容を確認した本人報告だけを使います。

内容や状況を確認中の投稿は、確認が済むまで点数の計算にも掲載にも含めません。

点数の計算

報告の割合と、出金可否の点数は異なります。

点数は、報告数が少ない場合の補正も加えて計算します。

3. 本人口コミ

会社についての口コミを、好意的・否定的・賛否ありに分けて点数にします。

採点期間直近の一定期間（固定）

口コミは、毎週末を目安に週1回集計し、更新する予定です。

口コミ内訳の見方

各社のページの口コミ内訳では、表示期間を365日・730日・全期間で切り替えられます。

期間を切り替えると、件数・割合・原文一覧が変わります。総合点と口コミタグは変わりません。

好意的・賛否あり・否定的をクリックすると対応する投稿を確認できます。

採点の流れ

  1. 1. 投稿を選ぶ

    投稿内容を確認し、評価に使う口コミを選びます。

  2. 2. 内容を分類する

    会社についての評価を、好意的・否定的・賛否ありに分類します。

  3. 3. 点数へ反映する

    会社に対する好意的・否定的・賛否ありの口コミの割合を、そのまま点数にはしません。

    • 最近の口コミをより重視して計算します。
    • 投稿者が少ない場合の補正も加えます。
    • 投稿の多い人がそのまま点数を左右しすぎないよう、投稿者単位で調整します。

評価に使う投稿の条件

対象にする

会社への評価が読み取れる口コミを対象にします。

採点から除く

  • 会社公式・運営側
  • 宣伝だけ
  • 会社評価のない本人の取引成績
  • 別会社・別商品
  • 重複の投稿

保留にする

根拠不足の投稿は保留し、確認が済むまで採点・掲載に含めません。

口コミタグの意味

好意的多め
口コミが十分にある会社のうち、好意的な投稿の割合が、掲載している会社の中で高い場合に表示します。
賛否あり
口コミが十分にある会社のうち、賛否ありの投稿の割合が、掲載している会社の中で高い場合に表示します。
最近悪化
直近の期間とその前の期間を比べ、否定的な投稿の割合が、ほかの会社と比べて大きく増えた場合に表示します。比べるのに十分な口コミがある会社だけが対象です。

3つのタグに共通する注意事項

タグは会社どうしを比べて付けます。同率の会社がある場合、タグが付く会社が多くなることがあります。

各社のページの不満の項目は直近6か月の投稿で数えています。口コミの採点には使っていません。

確認・保証できないこと

投稿や添付資料は確認の参考にしますが、記載された取引や主張が事実であること、証明書の内容が確かなこと、会社に責任があることを、このサイトが保証するものではありません。

同一人物が複数のアカウントから投稿しているかどうかは、完全には確認できません。また、異なる月の投稿が同じ出来事を指しているかどうかも、完全には確認できません。

4. 運営基盤

会社の出金の仕組みや運営の体制を、資料で確認して採点します。

採点する4項目

出金の仕組み
25点
公開収支
25点
運営体制
30点
支援元の規模
20点

4項目の合計は100点満点で、総合参考点の30％を占めます。

資料不足で加点していない項目もあります。確認済みの問題による運営基盤の減点は、各社のページの運営基盤の欄に表示します（まだ点検していないため、今はどの会社も0点で、「減点：未確認」と表示しています）。ルール変更の履歴による減点は、このページ下の「履歴変更の追加減点」で説明しています。

4項目で確認する内容

出金の仕組み

出金の条件や手順が明確か、出金できるかの判定から送金まで自動で進むか、出金処理の結果を追跡・確認できるかを見ます。

公開収支

誰が出金を支払い、その資金が何に使われるかを確認します。売上・支払額・運用で確定した利益や損失が公開され、同じ期間で比べられるかも見ます。あわせて、支払いに使う資金と、その支払いを負担する会社・組織の関係を確認します。

運営体制

サービスを提供する会社・組織と支援する組織が、実際の運営で何を担い、どこまで責任を持つかを確認します。継続してどのような支援を行うか、支援する組織が金融当局からどのような監督を受けているかも見ます。

支援元の規模

支援する会社の事業や利用者の規模を、確認できる数字で見ます。採点条件を満たす指標のうち、最も高い段階を1つだけ使います。

4項目で見る観点

各項目では、次の観点を確認します。観点ごとの配点は公開していません。

出金の仕組み
  • 条件・手順
  • 資格判定から送金までの自動化
  • 処理結果の追跡
公開収支
  • 支払主体・資金用途
  • 実現運用損益の公開
  • 支払額の公開
  • 売上の公開
  • 同期間の比較
  • 支払資金と負担の照合
運営体制
  • 提供主体・役割
  • 実際の運営関与
  • 責任・継続支援
  • 支援組織の金融監督
支援元の規模
  • 監査で確認された自己資本
  • 売上
  • 集計対象と期間が明確な実際の取引高
  • 金融サービスの認証済み会員数

5. 履歴変更の追加減点

すでに購入した人や既存の口座にさかのぼって不利な変更をした会社と、告知なしで重大な変更をした会社は、内容に応じて減点します。

対象になる変更

次のどちらかだけが対象です。

  • 不利益の追加・拡大が確認され、購入済み・既存口座への適用が確定した変更
  • 告知なしと確認された、警戒度の重い（S・A）変更

警戒度だけで一律減点しません。

減点の大きさ

S・A・B・Cは、その変更で増えた不利益の大きさを表す警戒度で、Sが最も重く、Cが最も軽い区分です。

警戒度が重いほど、減点は大きくなります。

  • 同じ会社に複数の変更があっても、減点が積み重なりすぎないように調整し、上限を設けています。
  • 同じ出来事が、出金可否の点数をすでに下げている場合は、その分を差し引いて減点します。
  • 出金可否の点数との重なりを確かめられない変更は、確かめられるまで減点を保留します。
  • 変更が撤回されただけでは減点を取り消しません。全面的な撤回と、影響を受けた人への救済まで確認できた場合は減点を軽くします。変更の事実が誤りだった場合は減点を取り消します。時間がたっただけでは減点はなくなりません。
